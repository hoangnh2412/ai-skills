# minipower-docs-outline

SOP **Outline** cho mặt `docs`. Pack tự chứa SOP; không phụ thuộc `sdlc/agents`.

## L1 / L2 / L3

Đọc tự do (L1). Mọi ghi collection/document = L3 sau một bảng.

Nếu MCP Outline không lên catalog: báo người sửa kết nối — skill không fallback sang Lark wiki.

## Cài

Atomic pack `docs/`. Điền `mcp.docs` trong `memory/profile.json`.

## Không làm

- Sửa template DOC trong `router/templates/`
- Coi Outline là nơi viết FR lần đầu khi dự án đang `docs_provider: local`
