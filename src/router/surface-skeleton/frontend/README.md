# Frontend

Code frontend đặt trong cây này — app Vite + React gắn kit `@platform/core`.

```text
frontend/
├── package.json · vite.config.ts · tsconfig.json · eslint.config.js
└── src/                 main.tsx · App.tsx · app/ · features/
```

App do skill `minipower-frontend-scaffold-react` dựng ngay tại `frontend/` (gốc app = gốc cây này). Feature nghiệp vụ đặt trong `src/features/`.
